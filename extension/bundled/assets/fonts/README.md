# Local fonts

All font requests stay on this origin. Geist and Geist Mono are the upright
variable webfonts from [Vercel's Geist](https://github.com/vercel/geist-font).
Newsreader Regular is an upright WOFF2 instance (weight 400, optical size 52)
of [Google Fonts' Newsreader](https://github.com/google/fonts/tree/main/ofl/newsreader).
Downloaded 2026-11-25. Each family's SIL Open Font License is included here.
