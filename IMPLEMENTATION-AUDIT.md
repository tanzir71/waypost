## Explicit interpretation and deployment boundaries

- The supplied UK conversion label conflicts with its specified percentage-band
  method: 72.4% produces First (estimate), rather than 2:1. The formula/method is
  retained and labelled. The supplied 3.81 course mix is reproduced independently
  of the deterministic greedy mix, which can concentrate upgrades differently.
  These discrepancies are also recorded under M4 in PROGRESS.md.
- GitHub Pages runs the complete static demo and distributes the self-hosting
  ZIP. It does not execute PHP or Workers. Optional sync, publishing and BYOK
  need a configured same-origin host. Owner server credentials/keys are not
  necessary for this release or its tests. Chrome's model requires actual browser
  support; provider fakes verify the adapters, not model availability or quality.
- Visual source comparison and native-contract tests do not prove pixel-perfect
  browser rendering, screen-reader behavior or every OS install integration.
  Those browser/manual QA gates are explicitly outside HANDOVER §13.
- Later tools, Bangla localisation, auto-apply, interview copilots, analytics,
  third-party auth/CDNs and GitHub Actions are not part of M0–M7.
