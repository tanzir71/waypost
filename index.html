Workflow

Collect → export → import → score. All browser-local by default.

Capture jobs

Save the current job title, link and visible description from the browser extension into local extension storage.

Organize by date

Captured jobs are grouped by the date they were collected, so batches stay tied to real search sessions.

Export selected dates

Pick one or more dates and download a TXT or JSON file. Nothing is sent directly to the scorer.

Score resume versions

Manually import the exported file, run matching, and compare which resume version fits each job cluster best.

Install extension

Install from the GitHub repo as an unpacked Chromium extension.

  1. Clone or download github.com/tanzir71/ats-scoring .
  2. Open chrome://extensions or edge://extensions.
  3. Enable Developer mode, choose Load unpacked, then select the extension/ folder.
  4. Capture jobs from job pages, export selected dates, then import the downloaded file in the scorer.

Built for private, file-based job search workflows.
