Honest match

Recruiters see tiers, not percentages.

Greenhouse Talent Matching groups candidates into match categories. Workday HiredScore uses grades A–D. Waypost reports per-requirement evidence, and keeps keyword coverage as a secondary number.

Sources: Greenhouse · Workday

MythA match score predicts the hiring decision.

FactYour report describes the text you supplied. Employers set their own criteria and application questions.

MythPDFs always fail a parser.

FactText PDFs can be readable. Scans, image-only content and unusual layouts need extra review.

MythStuff keywords to win.

FactShow truthful supporting experience. Waypost flags repeated terms and gaps in evidence.

For students

Plan the grades, not just the GPA.

Enter what you've earned and the GPA you need for the scholarship, the honours line or the grad-school cut-off. Waypost plans the least-effort grade mix across remaining courses — lock any grade you already know and it redistributes the rest.

For agents

Built for the agent in your browser.

Native controls with action names, private state in URL fragments, and every result mirrored as JSON. The live demo already exposes its report. Private links and feature-detected WebMCP tools are ready in the agent workspace.

  • Controls with a role and a name that says what they do
  • Results mirrored in a JSON script named result-data
  • Shared pure functions for the UI and agent tools
  • Static accessibility checks run with every milestone
